# Support

For questions about the notes, `dnnlpy`, notebooks, or the website, please [open a GitHub issue](https://github.com/jshn9515/deep-learning-notes/issues/new/choose) or email [jshn9510@gmail.com](mailto:jshn9510@gmail.com). Chinese readers can also contact me on RedNote: **jshn9515**. Search [existing issues](https://github.com/jshn9515/deep-learning-notes/issues) first in case your question has already been answered.

When reporting a problem, include the affected page or file, what you expected, what happened, and steps to reproduce it. For code or rendering problems, include the commands you ran, relevant error output, and your Python and package versions. Please remove tokens and other private information from logs before posting.

For larger changes or contributions, see [CONTRIBUTING.md](CONTRIBUTING.md). If you found a security vulnerability, follow [SECURITY.md](SECURITY.md) and report it privately instead of opening a public issue.
