# Accessibility

This project aims to make its English and Chinese notes, website, notebooks, and PDFs usable by as many readers as possible. Accessibility is an ongoing part of maintaining the project. This document does not claim that every page or format has been audited or meets a particular standard.

## Report a barrier

If you cannot access or use part of the project, please [open a GitHub issue](https://github.com/jshn9515/deep-learning-notes/issues/new/choose). Include the page or file, the barrier you encountered, and what you were trying to do. If helpful, include your browser, device, assistive technology, and any steps that reproduce the problem. You can also request the information in another accessible format through the same issue channel.

Reports about keyboard navigation, screen readers, image descriptions, math, color contrast, captions, and PDF reading are welcome. Please do not include private information in a public issue. For other support questions, see [SUPPORT.md](SUPPORT.md).
